# 幸存者 Demo 设计规格（需求提取用）

来源：用户粘贴的单文件 canvas 2D Demo（`幸存者 Demo`，非本项目代码）。此处只做**设计/数值提取**，作为给 DeepSeek / 豆包下需求的依据；实现仍然走 `src/` 的 Phaser + TS 分层。

## 1. 手感常量

| 项 | 值 |
|---|---|
| 玩家半径 / 血量 | 14 / 150 |
| 移动速度 | 260 px/s |
| 加速 / 减速 | 16 / 8（速度插值系数 → 起步快、松开滑） |
| 受击无敌 | 0.8 s |
| 拾取范围 | 100（初始） |
| 朝向 | 按速度平滑转向（18*dt） |

## 2. 经验与升级

- `expNeed(lv) = floor(3 + lv*2 + lv*lv*0.22)`
- 经验球：进入 `pickupRange` 后加速度 2600*dt 飞向玩家，阻尼 0.90，`dist < r+10` 吸收
- 升级即暂停 → 三选一 → `pendingLevels` 排队，一次只开一个面板

## 3. 武器表（7 把，lv 1–5）

| id | 名称 | 机制 | 伤害 | 冷却 |
|---|---|---|---|---|
| dart | 飞镖 | 追踪最近目标，同时 `1+lv` 发，lv4+ 穿透 2 | `22+lv*12` | `max(0.08, 0.30-(lv-1)*0.05)` |
| orbit | 环绕球 | 身周旋转 `2+lv*2` 个，半径 85，转速 3.0 | `14+lv*10` | 持续 |
| saw | 链锯 | 贴身 `2+floor(lv*1.5)` 把，半径 52，转速 6.5 | `30+lv*18` | 持续 |
| nova | 冲击波 | 周期性环形爆发 | `26+lv*18` | `max(0.5, 1.8-(lv-1)*0.22)` |
| chain | 闪电 | 同时劈最近 `2+floor(lv*1.2)` 个，射程 500 | `16+lv*12` | `max(0.2, 0.9-(lv-1)*0.1)` |
| laser | 激光 | 穿透直线，lv3+ 双发 | `30+lv*16` | `max(0.3, 1.2-(lv-1)*0.15)` |
| boomerang | 回旋镖 | `1+floor(lv/2)` 个，去回穿透 | `24+lv*14` | `max(0.5, 1.8-(lv-1)*0.22)` |

> 早期版本里还有三把「带代价的武器」，值得回收：**诅咒之刃**（伤害 65+lv*35，但每秒自伤 1.5+lv*0.4）、**吸血鬼牙**（伤害低，每次击杀回血 3+lv*2）、**散弹枪**（`5+lv` 发扇形，射程 0.28s、击退极强）。

## 4. 敌人表

| 类型 | 血 | 速度 | 半径 | 经验 | 行为 |
|---|---|---|---|---|---|
| normal | `14+w*7` | 70–95 随机 | 13 | 2 | 直线追踪 |
| fast | `12+w*5` | 145 | 10 | 2 | 直线追踪 |
| tank | `55+w*22` | 52 | 20 | 6 | 慢，方块 |
| triangle | `18+w*8` | 88 | 14 | 3 | 冲刺：cd 1.4–2.4s，0.35s @400px/s |
| splitter | `36+w*16` | 55 | 18 | 4 | 死亡分裂 2 个 fast（血 `8+w*3`） |
| shooter | `20+w*8` | 62 | 12 | 3 | 保持 220–360 距离，1.8s 一发弹 |
| **Boss 冲锋者** | `420+w*200` | 80 | 34 | 60 | 状态机，见下 |

Boss 状态机：`chase`(3s) → `charge_prep`(0.9s，画红色虚线预警) → `charging`(1.3s，950px/s) → 撞墙 `stunned`(3s，**受伤 ×3**) → 回到 chase。

## 5. 环境与掉落

- **木箱**：可破坏，血 `40+w*12`，挡路，碎后掉 3 个经验球 + 25% 概率掉道具
- **加速带**：圈内移速 ×1.55
- **回血泉**：圈内回 40 血，CD 14s
- **掉落物**（击杀 3%~12% 概率，Boss 必掉）：`heart` +35 血 / `magnet` 全图吸经验 / `bomb` 全屏 300 伤害

## 6. 关卡节奏

- `WAVE_LEN = 20s` 一波；每 5 波刷 Boss
- 刷新间隔 `max(0.05, 0.45 - wave*0.05)`，每帧最多 12 次；第 3 波起额外 55%、第 6 波起额外 35% 双刷
- 敌人总数上限 `MAX_ENEMY = 340`

## 7. 表现层（几乎全是「零资源手搓」，正好适配我们的水墨方向）

- **hitstop**：暴击 0.025s、Boss 死亡 0.12s、Boss 眩晕 0.2s（全局时间缩放 ×0.2）
- **震屏**：`shake` 指数衰减 0.86，暴击/Boss 加大
- **闪色**：受击红、Boss 粉、炸弹黄，全屏 `flashA` 衰减
- **玩家拉伸**：沿速度方向 `scale(1+0.22*spd, 1/(1+0.22*spd))` + 拖尾 + 无敌闪烁
- **发光**：`getGlow()` 复用同色同尺寸的离屏 canvas（缓存），`globalCompositeOperation='lighter'`
- 伤害飘字、连杀计数（1.6s 窗口）、脚步粒子、敌人受击白闪

## 8. 升级池

- 武器：已有则 `Lv.n → Lv.n+1`（权重 2.2）；未拥有则 `★ 新武器`（权重 3.5）
- 属性（权重）：力量 +20% 伤害 2.0 / 急速 -15% 间隔 2.2 / 疾风 +12% 移速 1.4 / 体魄 +30 上限并回等量 2.0 / 治疗 +50 血 1.4 / 磁力 +50 拾取 1.0 / 护甲 -10% 受伤 1.5 / 暴击 +10% 2.0

## 9. 与本项目 Phaser 版的差距（可直接转成需求）

| 能力 | Demo | 我们的 Phaser 版 |
|---|---|---|
| 武器 | 7 把 + 等级曲线 | 1 把（墨点直射） |
| 敌人 | 6 型 + Boss 状态机 | 2 型，直线追踪 |
| 环境物件 | 木箱 / 加速带 / 回血泉 | 无 |
| 掉落 | 血 / 磁力 / 炸弹 | 只有经验球 |
| 手感 | hitstop、震屏、拉伸、拖尾 | 只有震屏 + 受击墨点 |
| 升级池 | 7 武器 + 8 属性 | 12 条（豆包版，纯属性） |
| 连杀 / 波次 | 有 | 无（只有时间递增难度） |
